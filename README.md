# Fluxdesk

**Open Source Help Desk System**

O Fluxdesk é um sistema de Help Desk open source em desenvolvimento, projetado para centralizar o atendimento ao cliente e facilitar o gerenciamento de solicitações de suporte.

### Funcionalidades

- **Live Chat:** widget incorporável para atendimento diretamente em sites.
- **Caixa de entrada:** centralização e gerenciamento de conversas.
- **Kanban:** organização e acompanhamento de chamados.
- **Multi-organização:** ambientes independentes para diferentes organizações.
- **Autenticação JWT:** autenticação e controle de acesso de usuários.

### Status do projeto

🚧 O Fluxdesk está em desenvolvimento. Funcionalidades e arquitetura estão sujeitas a mudanças.

### Objetivo

Criar uma solução de suporte flexível, extensível e acessível, reunindo comunicação com clientes e gerenciamento de chamados em uma única plataforma.
